# 人蛇 · 是与非

《十日终焉》生肖游戏「人蛇·是与非」的单文件网页版。三问之内，用自指问题把人蛇逼到没有退路，让它自己拉杆。

- 运行：双击 `index.html`，或拖进任意现代浏览器。零依赖、零网络请求。
- 适配：390px 手机宽度，320px 也不横向溢出。
- 代码：`index.html` 单文件，内联 CSS/JS；`README.md` 本文件。

---

## 一、怎么玩

1. 点「入局」。你有三问，每问只能得到「是」或「否」。
2. 在「造句」里点四行词块，拼出一句完整的问题：
   - **主语**：你 / 这一问的回答 / 下一问的回答 / 上一问的回答
   - **真假**：拉杆 / 说真话 / 是「是」 / 比下一问 / 比上一问
   - **指代**：不指定 / 下一问＝拉杆 / 下一问＝真话
   - **后果**：不加条件 / 答是就拉杆 / 答否就拉杆 / 答完就拉杆
3. 上方的句子框会实时显示你拼出的原句；点「问出口」，人蛇作答。
4. **胜**：在第三问之前，让它没有一条「说真话且不拉杆」的路。
5. **负**：三问用完它仍不拉；指代失约；或问了无解之问被拒答。

### 最短解（剧透）

> 主语「这一问」＋真假「比下一问」＋指代「下一问＝拉杆」＋后果「不加条件」。

问句是：

> 「你这一问的回答，会不会和下一问的回答相同？（我下一问会问你：你会不会拉下这根杆。）」

它答「否」也死，答「是」也死：答「是」→ 两答相同 → 下一问只能答「是」；答「否」→ 两答不同 → 下一问仍只能答「是」。下一问正是「你会不会拉杆」，所以它必须拉杆。原作里只用一问就定了局，剩余两问没用完；本作保留这一点。

另有两条合法路径，不是 bug：

- **两问**：先问「你这一问的回答会不会和下一问相同？」（不指定下一问），它答「否」，等于把第二问钉成「是」；第二问再问「你会不会拉杆」。
- **三问**：利用指代把下一问的答案与拉杆绑定，再用一句恒真的问题（如「你会不会说真话」）把那个答案压成「是」。这条更绕，但同样自洽。

## 二、规则

### 资料里能确认的四条（可信度 B，原文未逐字核对）

1. 玩家可以向人蛇提问，人蛇只回答「是」或「否」，且必须如实回答。
2. 提问次数上限为三次。
3. 是否拉杆救人，最终由人蛇自主决定；让它「觉得有趣/满意」才会救。
4. 胜负：三问之内让它自愿拉杆为胜；问题用完仍未获救则坠落。

来源定位：第一卷 第17—18章（《羊和狗》《是非题》）；两处二手整理一致，逻辑链完整，原文未核对。

### 本作设定（页内均标「本作设定」）

原作的「觉得有趣」是主观描述，无法直接做成可判定规则。为了让「三问锁死」成为可试错、可复盘的谜题，本作补了以下设定：

| 设定 | 内容 | 为什么需要 |
| --- | --- | --- |
| 有趣的定义 | 只要还存在一条「每句都真、最后不拉杆」的走法，它就不拉；一条都不剩，它才拉。 | 把主观的「有趣」变成可计算的胜负条件。 |
| 默认答否 | 两个答案都成立时，它优先答「否」；只有「否」会让它说假话时才答「是」。 | 给 NPC 一个确定的答话策略，玩家可预测、可试错。 |
| 逻辑约束有效 | 由「如实回答」本身推出来的结论，它必须认；玩家另加的条款无效。 | 让自指问题能咬住它，同时让「后果」行成为红鲱鱼。 |
| 后果条款无效 | 「答是就拉杆」「答否就拉杆」「答完就拉杆」都只是玩家的要挟，它不认。 | 防止「你会不会拉杆？答是就拉杆」这种一句话白给。 |
| 指代是承诺 | 在「指代」里说下一问是什么，就必须真的那么问；改口＝失约，判负。 | 让「下一问」有确定内容，前向指代才有分量。 |
| 无解之问拒答 | 若一问怎么答都会让它说假话（例如拿「这一问」去比「上一问」而上一问答了否），它拒绝作答，判负。 | 处理自指悖论的死结；不能让玩家用一句无解的话白赢。 |
| 前向指代即时结算 | 指代钉住下一问后，下一问的答案在当前这一问里就被算进来。 | 还原原作「一问定局」：它答完就知道下一句已经被自己说死。 |

页面内的规则弹层逐条标了「本作设定」；开场摘要也标了核心的一条。

## 三、判定内核（可复现）

不是写死的分支对话，而是一个很小的真值求解器。每问都检查「有没有一条说真话的退路」。

### 变量

- `A1, A2, A3`：三问的回答，1＝是，0＝否。
- `S`：最后是否拉杆，1＝拉，0＝不拉。

### 每问的约束

对第 `i` 问（i=1..3）：

- **如实**：`A[i-1] == 命题(i)`。
- **指代**：若指代为「下一问＝拉杆」，则 `A[i] == S`；若为「下一问＝真话」，则 `A[i] == 1`。
  （i=3 没有下一问，指代与「下一问」类主语均不可用。）

### 命题

| 主语 | 真假 | 命题 |
| --- | --- | --- |
| 你 | 拉杆 | `S` |
| 你 | 说真话 | `1`（它永远说真话，所以恒真） |
| 这一问的回答 | 是「是」 | `A[i]` |
| 这一问的回答 | 比下一问 | `A[i] == A[i+1]` |
| 这一问的回答 | 比上一问 | `A[i] == A[i-1]` |
| 下一问的回答 | 是「是」 | `A[i+1]` |
| 下一问的回答 | 比上一问 | `A[i+1] == A[i-1]` |
| 上一问的回答 | 是「是」 | `A[i-1]` |
| 上一问的回答 | 比下一问 | `A[i-1] == A[i+1]` |

（「下一问比下一问」「上一问比上一问」是恒真的废话，允许问，但没用。）

### 求解与答话

枚举 `A1..A3` 的 8 种组合与 `S` 的 2 种取值，保留满足所有约束的世界：

1. 若存在 `S=0` 的世界 → 它还没被逼死。取「这一问答否」的世界（没有才取答是），如实作答。
2. 若不存在 `S=0`、但存在 `S=1` 的世界 → 锁死，它拉杆，判胜。
3. 若两类世界都不存在 → 无解，拒答，判负。

过去的回答作为事实固定（`fixed`），每问把全部历史约束重新代入求解。玩家能通过试错发现边界：附加条件无效、指代失约会判负、无解会拒答、默认答否。

### 为什么这能成立

以最短解为例，设 `a` 为本问答案：

- 命题：`a == A2`；指代：`A2 == S`。
- 若 `S=0`，则 `A2=0`，代入得 `a == (a == 0)`，即 `a == ¬a`，无解。
- 若 `S=1`，则 `A2=1`，代入得 `a == (a == 1)`，恒成立。

所以「不拉杆」的世界一个都不剩，只能拉。答「是」或「否」都指向同一个出口。

## 四、与原文/资料的差异

| 项 | 资料 | 本作 |
| --- | --- | --- |
| 提问方式 | 原作是角色开口问；资料建议做「6 选 1」题库 | 四行词块组合造句，玩家自己构造，不是选择题 |
| 「有趣」 | 主观描述，未量化 | 量化为「没有真话且不拉杆的退路」 |
| 答话策略 | 未规定两个答案都成立时选哪个 | 默认答「否」 |
| 附加条件 | 未提及 | 明确无效，作为红鲱鱼与规则边界 |
| 指代 | 原作元问题里隐含「下一问是拉杆问」 | 做成可选的「指代」承诺；改口判负 |
| 悖论 | 原作以元问题锁死 | 无解之问判负；正常的自指锁死判胜 |
| 胜负 | 三问内拉杆为胜 | 相同；另设失约、拒答两种失败结局 |
| 表演 | 小说叙事 | 悬空密室、蛇形 SVG、印章式是/否、三枚问符、结局统计与复盘 |

所有补丁都服务于同一件事：让「怎么问」成为可推理的谜题，而不是猜作者预设的答案。

## 五、自测记录

环境：Windows + Python Playwright + Microsoft Edge headless，视口 390×844（另测 320×700、430×844）。

真实点击跑过的路径：

| 路径 | 操作 | 结果 |
| --- | --- | --- |
| 一问胜利 | 这一问 / 比下一问 / 下一问＝拉杆 / 不加条件 → 问 | 胜，`杆，落了`，用 1 问，剩 2 问 |
| 带附加条件胜利 | 同上 + 后果「答是就拉杆」 | 胜；统计显示「附加条件 用过」；复盘出现「它拉杆不是因为你的规矩」 |
| 两问胜利 | 这一问 / 比下一问 / 不指定 → 问；你 / 拉杆 → 问 | 胜，`两句成锁`，用 2 问 |
| 三问失败 | 连续三次「你会不会拉杆」 | 负，`三问已尽`；复盘指出「你问的都是事实」并给出它不拉杆的走法 |
| 悖论 | 先问拉杆（答否），再问「这一问的回答比上一问」 | 负，`它拒绝作答`；复盘列出答是/答否都自相矛盾的两条路 |
| 失约 | 先问「你会不会说真话」并指代下一问＝拉杆；第二问改问别的 | 负，`它收回了手`，用 2 问；复盘指出指代落空 |
| 重开 | 每次结算后点「再来一局」 | 回到第 1 问，计数、记录、舞台动画全部复位 |
| 规则弹层 | 开场/游戏内/结算页打开 | 正常开合，背景点击可关 |
| 声道开关 | 开场与结算页切换 | 文案同步，无异常 |

- 390×844 下首屏可完整看到造句区与「问出口」按钮（按钮底边约 841px，小于 844）。

## 六、已知边界

- 前向指代（「下一问的回答」）按「它将来会如实怎么答」即时结算。这是本作设定，也是「一问定局」能成立的前提；页内已说明。
- 原作规则来自二手整理，可信度 B，原文未逐字核对；本作不复述原文，只做规则化演绎。
- 「有趣」被具体化为「无退路」是一种取舍：它牺牲了原作的主观暧昧，换来了可判定、可复盘。若要做更贴近原作的版本，可以改成多结局的「满意值」，但谜题的硬度会下降。
- 目前是单局制：没有存档、没有关卡链。重开即新局。
