# 地鼠 · 猫鼠游戏

《十日终焉》生肖游戏「地鼠」的网页版。玩家操控三只鼠，在六昼夜的循环里采集果实、投果续命、凑五行钥匙打洞，躲避一只会巡逻、搜捕、设卡的猫。

- 入口：双击 `index.html`（单文件、内联 CSS/JS、零依赖、零网络请求）
- 适配：桌面与手机 390px，全部操作为点击（键盘 1/2/3 可切鼠）
- 规则来源：`SPEC.md`（405 行，本项目唯一规则来源；未写明的部分按「本作设定」补全）

## 怎么玩

1. 选难度（简单 / 普通 / 困难），可选种子；首局强制走完 7 页教程。
2. 夜：每只鼠独立 AP，点地图相邻房间 + 动作按钮。移动、探查、搜寻、搬运、打洞、营救、清扫各 1 AP；屏息、投果、存果 0 AP。「探查并搬空」是合并操作：先花 1 AP 确认夹子，安全再花 1 AP 搬走本房剩余果实，AP 与分开点完全相同，只为少点几下。
3. 黎明：没回鼠屋的鼠露宿；没洞的房间会落锁（不能移动），需要相邻队友营救或带钥匙打洞。
4. 白天：鼠不能动，只能看猫逐个动作（可「下一动作 / 自动播报 / 加速」）。
5. 夜尽：所有活鼠与猫饱腹 −1，鼠归零饿死。撑过第 6 昼夜夜尽仍有自由鼠即胜。

## 本作设定（SPEC 未写明处的补全）

- **地图**：3×3 环形，木房 / 火房 / 金房 / 鼠屋 / 中央大厅 / 猫屋 / 水房 / 土房 / 东廊。邻接与 SPEC §6 一致。
- **猫的信息边界**：猫只知道所在房、相邻房的果实；不做全图嗅探。确定线索来自目击、踩夹红灯、搜寻扑空后的记忆（2 回合）。
- **猫的决策顺序**：眼前同房 / 踩夹红灯的确定线索优先于「饿了吃果」（抓鼠 +2 饱腹更划算）；只有 2 回合前的旧记忆不如先吃一口。这样玩家看到的是「猫先追看得见的鼠，再回去吃饭」，而不是放着眼前的鼠跑去金房。
- **夜宿与减员压力**：鼠屋床位为简单 3、普通/困难 2。普通/困难下减员不会更安全：鼠屋只收留「存活数 − 1」只（至少 1 只在鼠屋外放哨），2 鼠时仍强制 1 只露宿；最后 1 只可睡鼠屋，保留残胜可能。
- **猫屋干粮**：开局 3 颗。猫饱腹为 0 时，入夜先吃 1 颗干粮回到 1；干粮耗尽后整夜无动作，日志写「猫趴在猫屋不动」。
- **设卡**：普通难度第 3 回合起，猫会先走到最近的无卡出口再设卡；困难难度第 3 张卡对玩家隐藏显示为「卡?」。卡持续到下一次入夜后失效。
- **守出口**：第 4 回合起，猫在木房 / 水房 / 中央按痕迹与当日搜寻次数评分蹲守；普通守最优 1 个，困难单双回合轮流守分数最高的 2 个出口。
- **痕迹**：探查 / 搜寻 / 搬运各使本房 +1 痕迹（上限 3），移动不产生。阈值简单 3、普通 2、困难 1；达阈值后猫会循迹。教程第 6 页、规则速查和动作按钮副标题均有说明。
- **入夜提示**：按当前饱腹动态计算本夜需要带回的果实数；第一夜饱腹已满时明确提示「投果会被拒绝，请先存入储藏」。
- **教学策略**：每次开局都会显示 7 页教程；首局「跳过」禁用，完成一次后可跳过（仍显示，符合 A17）。
- **重开**：结局屏「重开一局」沿用同一 seed 与难度重建整棵状态树（§7.4）；「换难度」回到难度选择。
- **存档**：整棵 `GameState` 写入 localStorage；标题屏「继续上局」。file:// 下若浏览器禁写 localStorage，会静默降级为仅本局可玩。
- **评分与道**：胜利时 30 道按幸存鼠数均分（3/2/1 鼠 → 10/15/30）；评级 S=三鼠齐活且 0 次夹子，A=三鼠齐活，B=剩两只，C=剩一只。失败 0 道。
- **界面补强**：顶部五段阶段条（入夜 → 夜行 → 黎明 → 白昼 → 夜尽）、危险提示带（饱腹 1/2、被困、红灯、设卡）、回合结算中的「道 · 若现在结算」、结局屏的「本局亮点 / 失败复盘」。
- **可复现**：夹子位置、命中掷骰、邻房察觉全部走同一 mulberry32 伪随机流（`seed` / `rngState`），同 seed 同操作序列结果一致。

## 已知限制

- S8 的「饱腹 −1 动画」以数值变化与结算面板呈现，没有逐格补间动画。
- 猫 AI 是 SPEC §5 优先级的启发式实现，不是最优解；极端布局下可能来回巡逻。
- 普通 / 困难下「三只鼠全回家」时，被强制露宿的鼠默认去中央大厅；中央紧挨猫屋，第一白天被搜概率高。这是床位压力与打洞动机的设计取舍，已在黎明弹层给出「留一只在远处房间过夜」的提示，但不是强制引导。
- 教程每次开局都会出现（首局不可跳过），熟练玩家需多点一次「跳过」。
- 仅本机 localStorage 存档，无云同步、无回放、无联机。
- 纯点击操作；未做拖拽、手柄与读屏器专门适配。
