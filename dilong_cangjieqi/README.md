## 一、玩法（网页版）

1. **开局**：进入「凤凰衔书台」，28 个待成字排成四行（每局显示顺序随机）。
2. **拆合**：点一个字 → 下方出现部件槽（左/右、上/下，或品字三格）。在部件盘点一枚部件，再点槽位放入；点已填的槽可撤换。成字后自动接续下一个未成字，省一次点选。
3. **成字**：槽位填满即判。部件齐、位置对 → 成字 +1；错 → 墨散、记一次失手、污染 +25。墨散会逐格说明「某格应放什么、你实际放了什么」，对的格子保留。
4. **竞速**：AI「地龙」同步拼自己那份字帖，双进度条实时可见，其速度跟随玩家近期成字节奏浮动（快则快、慢则慢）。污染满 100（四次失手）即精神崩溃，直接判负。
5. **战场**：先凑齐 28 字者占先手。三门里**夺下 2 门**即生；落后者须**三门全夺**，一门失守即死。前两门在墨线爬满前点齐部件，**首错只污墨清空、再错才锁门**；第三门是「辨字」四选一，点错即锁门。每门开门有 1.5 秒缓冲，读字不计时。
6. **结算**：门数达标者「生」，否则「死」；显示成字、失手、污染、用时、战场比分、问字次数，并复盘每一门结果、竞速差距与最后一次墨散；本机最快破锁时间存入 localStorage。

辅助：3 次「问字」（直接给出当前字的拆法并高亮部件）、「清格」、声音开关、规则页。

## 四、字库与校验

**15 枚部件**：木 目 口 十 人 亻 八 火 士 寸 夕 马 包 亠 丘

来源（常用部件拆法，非严格字源）：相→木+目；仕→亻+士；炮→火+包；兵→丘+八；马→马；象→⺈+口+豕（取「口」）；将→丬+夕+寸（取「夕、寸」）；卒→亠+人+十（取「亠、人、十」）。

**28 字**（`|` 表示结构分界；品字结构为 上 / 左下 / 右下）：

- 左右（13）：相 木|目；休 亻|木；仕 亻|士；伙 亻|火；林 木|木；村 木|寸；付 亻|寸；什 亻|十；叶 口|十；吗 口|马；从 人|人；叭 口|八；咆 口|包
- 上下（10）：杏 木|口；呆 口|木；吉 士|口；古 十|口；只 口|八；名 夕|口；六 亠|八；炎 火|火；吕 口|口；兵 丘|八
- 品字（5）：森 木|木|木；焱 火|火|火；众 人|人|人；品 口|口|口；骉 马|马|马

校验原则：

1. 每个字都是真实存在的汉字，写法按通用简体字形；
2. 每个字的所有部件都在 15 枚部件表内（页面初始化时断言 `missing` 为空）；
3. 结构分界与槽位一一对应：左右结构左槽/右槽，上下结构上槽/下槽，品字结构上/左下/右下；
4. 同部件不同结构互为考点：呆（上口下木）与杏（上木下口）、只（上口下八）与叭（左口右八）——位置错即判错，这是本作「拆字手感」的核心。

**取舍说明**：档案七子里的「车」为独体，本关 28 字不受车部，故未进部件盘；「帅」整体不可拆，也未进盘。这是字库取舍，不是遗漏。

## 五、AI 与数值

- 地龙每字耗时 = 玩家近期成字间隔（EMA，截断在 1.1–7.0 秒）× 1.05 + 0.26 秒，抖动 ±12%，并截断在 1.45–5.2 秒；约 10% 概率「失手」额外 +1 秒。玩家快它快、玩家慢它慢，竞速通常贴得很近。
- 玩家成字无冷却，只受「污染」与操作速度限制；成字后自动选中下一个未成字。
- 污染：每次失手 +25，满 100 判负。
- 战场：开门缓冲 1.5 秒（不计墨线）；前两门墨线 9.2 / 8.4 秒，第三门「辨字」7.0 秒；前两门首错只清空已选（污墨），再错锁门；第三门一次定生死。
- 胜负：先手方（先凑齐 28 字）三门夺二；落后者须三门全夺。失败两门即死。
