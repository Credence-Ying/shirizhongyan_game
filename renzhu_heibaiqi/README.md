# 人猪 · 黑白棋（网页版）

《十日终焉》人级生肖「猪」的第 7 关，做成可反复试的单文件小游戏。

**打开方式**：双击 `index.html`。单文件、内联 CSS/JS、零外部依赖、零网络请求，`file://` 下即可完整游玩。

---

## 一、玩法

1. **分配**：把 50 黑 + 50 白共 100 颗分进甲、乙两只碗，两只碗都不能空。用两个滑块调黑子、白子，实时看到本局胜率。
2. **押注**：每局押 1—5 道（不超过手上的道）。赢 `+押注`，输 `−押注`。押到 **4 道起**，裁判先手往每只碗压 1 颗白子；押到 **5 道**，两只碗还必须各装够 30 颗——押得狠，规矩就紧。
3. **试摸**（可选）：开赌前可免费模拟 1000 次，看理论胜率和实测差多少。
4. **确认分配** → 两只碗扣住并随机换位 → 点一只碗摸一颗 → 摘眼罩看结果。
5. 一局结束给复盘：本局天花板、你的差距、最优摆法；然后进下一局。
6. **五局**打完结算；中途道归零则当场「留下」。

结算档位：净输赢 ≥ +8「满载」/ ≥ +3「全身」/ −2~+2「白坐」/ < −2「亏空」/ 道 ≤ 0「留下」。

## 三、74.7% 是怎么来的

蒙眼、且两碗已随机换位，所以选中甲碗 / 乙碗各是 ½：

```
P = ½ × (甲碗黑子 / 甲碗总数) + ½ × (乙碗黑子 / 乙碗总数)
```

甲碗只放 **1 颗黑子**（100%），剩下的 49 黑 50 白全进乙碗（49/99 ≈ 49.49%）：

```
P = ½ × 100% + ½ × 49.49% = 74.75%
```

**为什么必须随机换位**：若碗的位置固定、玩家知道哪只是甲，就会永远挑 100% 的那只，胜率变 100%，公式里的 ½ 失效。本作在扣碗时随机交换甲乙位置，玩家只能「挑碗」，不能「挑棋子」。

**为什么「等重」局只有 50%**：两碗总数相等时，`P = ½×(b/50) + ½×((50−b)/50) ≡ 50%`，滑块怎么动都不变——这一局是故意给出的反例，用来教「约束会锁死概率」。

## 五、实际游玩记录（本轮打磨的依据）

用无头浏览器按三种打法各走一遍完整五局：稳健最优（押 2）、默认 25/25（押 2）、押大（押 4—5）。记录如下：

| 观察到的现象 | 改动 |
| --- | --- |
| 第 3 局起操作开始重复：三关都是「黑子推一边、白子推另一碗」，只是数字变了 | 加「押注—规则」耦合：押到 4 道起裁判先手压白子（天花板 74.7%→68.0%），押到 5 道再要求两碗各 30 颗（→63.3%），每关都多出「摆法多赚几点 vs 押注多赚一倍」的取舍；复盘按局给不同挪法（留白局只能挪黑、厚底局把白全推走、见色局留 1 白兜底） |
| 等重局拖动滑块，胜率恒 50%，界面沉默，像坏了 | 拖动即时提示「½×a + ½×(1−a) 恒等于 50.0%，这一局只剩押注能选」；曲线图右侧标「平线」，标题改「怎么摆都是 50.0%」 |
| 输了却写「你摸到了本局的天花板」，语义打架 | 拆成两句：「这一摆已经到顶。这一摸没中，输的是运气，不是摆法」；差距用「比天花板低 24.7 个百分点」并附可执行挪法 |
| 第 3 局道就归零，事前毫无预警，第 4/5 关根本没玩到 | 押注栏按存量显示「连输 N 局就留下」（N ≤ 3 时才提示）；复盘加「离满载（净 +8）还差 X 道」 |
| 点碗后立刻能摘眼罩，中奖感廉价 | 换位时给一句「你只能挑一只碗，挑不了碗里的棋子」；选碗后按钮先禁用 480ms，显示「手还伸在碗里…」 |
| 结算只有输赢总额，缺少「离完美还差多少」 | 结算加「摆法到顶 X / N 局」「平均还差 Y 分」，并把最高摆法单独列出 |
| 曲线图只画当前点，看不出「最高在哪」 | 图上标出空心峰值点「最高 74.7%」，等重局则标平线说明；无效区间保留断线 |

以下为未改动、但记录在案的判断：五关的**分配动作**本质仍是同一个优化（把黑子收进一只碗），本作没有强行加第六种机制；差异改由约束、押注耦合与每关不同的挪法说明来承担。

## 七、实现说明

- 单文件：HTML + 内联 CSS + 内联 JS，无 CDN、无字体外链、无图片请求。
- 概率：`prob(b,w)` 解析式；最优：`optimum()` 枚举 + `valid()` 约束。
- 试摸：按碗内黑子比例抽样 1000 次，`requestAnimationFrame` 计数动画，结果与理论值并列显示。
- 棋子：每碗预建 100 个 `<i>`，按黄金角螺旋排布、黑白按比例穿插，按数量分级尺寸（1—4 颗时放大，避免看起来像空碗）。
- 战绩：`localStorage` key `renzhu_heibaiqi_v1`（累计轮数/局数/胜局/最高单局胜率/算纸解锁）。
- 只读测试钩子：`window.Game.snapshot()` 返回当前状态快照，`window.Game.probe.optimum()` / `valid()` 用于复核天花板与约束，均不影响玩法。
